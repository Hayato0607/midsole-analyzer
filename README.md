# ミッドソール圧縮アナライザー

真横から撮ったランニングシューズのスロー動画から、接地中のミッドソールの厚みの変化を追い、ヒール・ミッド・フォアの圧縮率（%）を出すWebアプリです。動画はブラウザの中だけで処理され、どこにも送信されません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（ボタン、説明文など） |
| `style.css` | 見た目（色、文字、レイアウト） |
| `app.js` | 画面の動き（動画の読み込み、再生、点のドラッグ、グラフ、CSV書き出し） |
| `core.js` | 解析の中身（靴とミッドソールの自動検出、追跡、厚みの推定） |
| `event.js` | 体験会モード（事前入力、2足×複数歩の比較、主観評価、適性距離の推定、データの書き出し） |

## ローカルで使う・編集する

`index.html` をChromeかEdgeで開けば、そのまま動きます（サーバー不要）。ファイルを編集して保存し、ブラウザを再読み込みすると反映されます。

## 体験会での使い方（適性距離推定ルール v0.1）

1. 「体験会・比較」タブの設定で、シューズA（MS5）・B（YOGIRI SPEED）の名前と撮影fpsを確認する
2. 「＋ 参加者を追加」で参加者を作り、事前入力（自己ベスト、目標レース、練習量、走り方の好みなど）を入れる
3. 「解析」タブで保存先の参加者とシューズを選び、1歩ずつ解析して「この歩を追加」を押す（1足あたり5歩以上が目安。撮影の順番は参加者番号で自動的に入れ替わる）
4. 走った直後に、2足それぞれの主観評価（9項目・5段階）を入力する
5. 「結果シート」に距離ごとの使い分け（MS5／どちらでも／YOGIRI）と、境界を動かしたルールの根拠が出る。「スタッフ用チェック」も確認してから説明する
6. 終わったら「全員分をCSVで書き出す」と「歩ごとのCSV」。途中でも「バックアップを書き出す」でJSONを保存しておく

推定ルールの中身は `event.js` の `estimate()`（基本境界と補正A〜F、注意フラグ）と `staffChecks()`（品質チェック）にまとまっています。しきい値の一部は画面の「判定の詳細設定」から変えられます。

参加者データはブラウザの localStorage に保存されます（動画は保存しません）。別のPCに移すときはバックアップのJSONを読み込んでください。

## GitHubに公開する（初回）

1. GitHubで新しいリポジトリ `midsole-analyzer` を作る（READMEなどは追加しない）
2. このフォルダでターミナル（PowerShell）を開いて実行する

```
git init
git add .
git commit -m "ミッドソール圧縮アナライザー 初版"
git branch -M main
git remote add origin https://github.com/Hayato0607/midsole-analyzer.git
git push -u origin main
```

3. リポジトリの Settings → Pages → Build and deployment で、Source を「Deploy from a branch」、Branch を `main` と `/(root)` にして Save
4. 1〜2分後に `https://hayato0607.github.io/midsole-analyzer/` で開けるようになる

## 編集したあとに更新する

## 注意
