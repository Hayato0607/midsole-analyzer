# ミッドソール圧縮アナライザー（マラソンペース適合プロファイル）

同じランナーが2足のランニングシューズをマラソンレースペースで履いて走ったスロー動画から、ミッドソールの変形を比べ、「長時間走で試す第1候補」「明確な差なし」「判定保留」を返すWebアプリです。動画はブラウザの中だけで処理され、どこにも送信されません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（ボタン、説明文など） |
| `style.css` | 見た目（色、文字、レイアウト） |
| `app.js` | 画面の動き（動画の読み込み、接地・離地の指定、解析、点のドラッグ、グラフ、CSV書き出し） |
| `core.js` | 解析の中身（靴とミッドソールの自動検出、追跡、厚みの推定） |
| `event.js` | 体験会モード（事前入力、2足×左右の比較、サブスコアと判定、主観評価、データの書き出し） |

## ローカルで使う・編集する

`index.html` をChromeかEdgeで開けば、そのまま動きます（サーバー不要）。ファイルを編集して保存し、ブラウザを再読み込みすると反映されます。

## 体験会での使い方

1. 「体験会・比較」タブの設定で、シューズA・Bの名前と撮影fps（必須）を確認する
2. 「＋ 参加者を追加」で参加者を作り、目標マラソンペース・月間走行距離などを入れる
3. 「解析」タブで、保存先の参加者・靴・脚（右／左）を選ぶ。動画を読み込み、靴がはっきり写るフレームで自動検出し、接地と離地のフレームを指定して解析し、「この歩を追加」を押す。保存先は「1足目の右→左、2足目の右→左」の順に自動で切り替わる。測るのはカメラ側の外側だけ
4. 走った直後に、2足それぞれの主観評価（違和感・走り続けやすさ）を入れる
5. 結果に「長時間走で試す第1候補」「明確な差なし」「判定保留」のどれかと、サブスコア3つ・理由・限界が出る。判定信頼度は常に「限定的」
6. 終わったら「全員分をCSVで書き出す」と「歩ごとのCSV」。途中でも「バックアップを書き出す」でJSONを保存しておく

判定の流れ（`event.js` の `decide()`）：品質ゲート → 計算できるかの確認（ここまでで当たれば判定保留）→ 左右の向きの確認・指標の競合（当たれば明確な差なし）→ 合計点の差 ÷ 基準差（D）が1.0以上なら第1候補、未満なら明確な差なし。主観評価は継続許容性の点数にだけ使い、除外条件にはしません。サブスコアの計算は `cushionLeg()`・`lrShoe()`・`contShoe()`、しきい値と重みは画面の「判定の詳細設定」から変えられます（いずれも暫定値）。月間走行距離が150km未満の人は、クッションの使い方で底つきまでの余裕を重く見ます（`MONTHLY_LOW`）。

参加者データはブラウザの localStorage に保存されます（動画は保存しません）。別のPCに移すときはバックアップのJSONを読み込んでください。

## 赤いテープ（任意）

ミッドソール側面のカメラ側に、赤い丸テープ（直径5〜8mm、つや消し）を、かかとから靴の全長の約15%（リア）・42%（ミッド）・68%（フォア）の位置に貼っておくと、自動検出のときにテープを見つけて、測定点をテープのすぐ横に合わせます（テープ自体の縁を境目と間違えないよう、少し横で測ります）。1か所に上下2点貼っても構いません。テープは上端・下端の境目から少し離して貼ってください。見つからなかった部位は、靴の長さの15%・42%・68%に置きます。

## GitHubに公開する（初回）

1. GitHubで新しいリポジトリ `midsole-analyzer` を作る（READMEなどは追加しない）
2. このフォルダでターミナル（PowerShell）を開いて実行する

```
git init
git add .
git commit -m "ミッドソール圧縮アナライザー 初版"
git branch -M main
git remote add origin https://github.com/Hayato0607/midsole-analyzer.git
git push -u origin main
```

3. リポジトリの Settings → Pages → Build and deployment で、Source を「Deploy from a branch」、Branch を `main` と `/(root)` にして Save
4. 1〜2分後に `https://hayato0607.github.io/midsole-analyzer/` で開けるようになる
