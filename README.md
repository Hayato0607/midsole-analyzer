# エアロエリート相性チェック（ミッドソール圧縮アナライザー）

スケッチャーズ「エアロエリート」を履いて走ったスロー動画から、ミッドソールの潰れ方を解析し、走りとの相性を0〜100点で示すWebアプリです。動画はブラウザの中だけで処理され、どこにも送信されません。

以前の「2足比較（マラソンペース適合プロファイル）」版は、このリポジトリのコミット履歴に残っています。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（はじめに／解析／相性チェックの3タブ） |
| `style.css` | 見た目 |
| `app.js` | 解析タブの動き（動画の読み込み、接地・離地の指定、解析、点のドラッグ、グラフ） |
| `core.js` | 解析の中身（靴とミッドソールの自動検出、赤いシールの検出、追跡、厚みの推定） |
| `event.js` | 相性チェック（参加者の管理、相性スコア、結果画面、CSV・バックアップ） |

`index.html` をChromeかEdgeで開けば、サーバーなしで動きます。

## 当日の使い方

1. 「相性チェック」タブの設定で、撮影fps（必須）を入れる
2. 「＋ 参加者を追加」で参加者を作り、申込内容（目標ペース、月間走行距離、サイズ、同意、SNS掲載の可否）を入れる
3. 「解析」タブで動画を読み込み、靴がはっきり写るフレームで「自動検出」→ 接地と離地のフレームを指定 →「解析する」→「この歩を追加」。保存先は右足→左足の順に切り替わる
4. 走った感覚（2問）を入力する
5. 「相性チェック」タブの結果を説明する（参加者が画面を動画に撮ってよい）
6. 枠の合間に「バックアップを書き出す」。終わったら「全員分をCSVで書き出す」と「歩ごとのCSV」

## 相性スコアの計算（`event.js` の `evaluate()`）

- **クッションの使い方（重み50%）**：動画の最大圧縮率 × 校正係数を、シューズの基準（下限・目安・上限）に当てはめ、活用 U と余裕 R を出す。着地のタイプ（リア／ミッド／フォア）の重みで部位を合計し、`100 ×（a × 活用 +（1 − a）× 余裕）` を左右で平均する。a は通常0.5、月間走行距離が100km未満なら0.4
- **左右のそろい具合（重み30%）**：部位ごとの最大圧縮率と、最大圧縮のタイミングの左右差。差0%で100点、50%以上で0点
- **走った感覚（重み20%）**：違和感と走り続けやすさの2問。未入力ならスコアに含めない
- 80点以上「相性が良い」、60〜79点「十分使える」、60点未満「力を引き出しにくい可能性」。活用が0.35未満のときは、点数が高くても「十分使える」まで
- 追跡の品質不足、接地・離地の未入力、動画ごとの解像度・fpsの不一致があるときは、点数を出さず「スコア保留」

基準値・校正係数・重み・しきい値は、画面の「判定の詳細設定」で変えられます。**エアロエリートの試験機データがないため、基準（ヒール35/55/68%、フォア47/58/66%）と校正係数3は仮の値です。** 本番前にテスト撮影をして調整してください。

## 赤い丸シール

シューズ外側のミッドソール側面に、かかとから全長の約15%・42%・68%の位置に赤い丸シール（直径5〜8mm）を貼ると、自動検出のときに測定点をシールのすぐ横に合わせます。上端・下端の境目からは少し離して貼ってください。
