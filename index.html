ミッドソール圧縮アナライザー

2足をマラソンレースペースで履いて走ったスロー動画から、ミッドソールの変形を比べる「マラソンペース適合プロファイル」です。

マラソンペース適合プロファイル

同じランナーが2足のシューズをマラソンレースペースで履いて走ったスロー動画から、ミッドソールの変形を比べて「長時間走で試す第1候補」を示します。差がはっきりしないときは、無理に推奨せず「明確な差なし」や「判定保留」を返します。

流れ

  1. 参加者を追加し、目標マラソンペースなどを入力する
  2. 2足それぞれ、マラソンペースで真横から撮影する（右脚・左脚とも、カメラ側の外側が写るように）
  3. 「解析」タブで1歩ずつ、接地と離地を指定して解析し、参加者の枠に追加する
  4. 走った直後に主観評価（2問）を入力する
  5. 結果（第1候補／明確な差なし／判定保留）と、理由・限界を説明する

結果の見方

  • 結果は「長時間走で試す第1候補」「明確な差なし」「判定保留」のどれかです。
  • サブスコアは3つ（クッションの使い方・左右整合性・継続許容性）で、総合点は出しません。
  • 判定信頼度は、今回の測定条件では常に「限定的」です。おすすめ度とは別に表示します。

撮影のポイント

  • カメラはミッドソールの高さで、進行方向に直角に固定する
  • 靴全体と接地面が画面に入るようにする（端で切れない）
  • 120fps以上、できれば240fps以上で、明るい場所で撮る
  • 加速・減速中ではなく、一定ペースで走っている区間を使う
  • 右脚と左脚の外側は、カメラを左右に置くか、往復で撮る（すべての動画を同じfps・解像度にする）
  • ミッドソールの外側に赤い丸テープを、かかとから全長の約15%・42%・68%の位置に貼ると、測定点が自動でテープに合う
  • 顔が映る場合は、トリミングしてから使う

この結果でわからないこと

  • 医学的な診断、故障の予防、過回内・回外の診断はしません。
  • ランニングエコノミー、反発力、エネルギーリターンは評価しません。
  • 5km・10kmなど、マラソンペース以外の速度での適性は判断しません。
  • 疲労後の変化や、フルマラソン後半のフォームは評価していません。
  • 真横から見た見かけの変形からの推定で、判定の基準値は暫定値です。

圧縮率の推移

ヒールミッドフォア

グラフをタップするか左右にドラッグすると、そのフレームに移動します。破線の縦線が無負荷の基準フレームです。線が途切れている所は、画面外や追跡不良で測れなかったフレームです。

厚み方向の時系列

各測定位置の厚み方向の画素を時間順に並べた画像です（縦が厚み方向、横が時間）。上下2本の線がミッドソールの上端と下端の境目に沿っていれば、正しく追えています。

  1. 動画を読み込む

    靴の真横から、ソールの高さで撮ったスロー動画を使います。

    iPhoneのスロー動画を書き出したファイルは通常30fpsです。

  2. ミッドソールを指定

    靴がブレずにはっきり写っているフレームに移動してから検出します。

    うまく合わないときは、動画の上でミッドソールの上端から下端までを囲むようにドラッグしてください。各点はドラッグで動かせます。

  3. 接地と離地を指定する

    靴が地面に着いた瞬間と、離れた瞬間のフレームを指定します。接地の瞬間が無負荷の基準になります。

  4. 解析する

  5. 結果を整える

    上げると厚みの細かい揺れを抑え、下げると急な変化に素早く追従します。測定点がずれているフレームでは、点をドラッグして正しい境目に合わせると、その前後の追跡もやり直します。

    接地時間をミリ秒で出すのに使います。体験会で保存するには必須です（「体験会・比較」タブの設定と共通）。

    長さの分かる目印が写っていれば、両端をクリックすると厚さをmmでも記録します（任意）。

測定の前提と注意
  • 真横から見たミッドソール側面の、見かけの厚みの変化です。カメラの角度、足の内外への傾き、レンズの歪みで数%単位の誤差が出ます。
  • 厚みが100 pxなら1 pxの誤差が1%に相当します。靴を画面いっぱいに大きく写すほど精度が上がります。
  • 撮影はカメラを固定し、ソールの高さで真横から。靴底の下に地面が少し写るようにすると、下端が画面外に切れません。明るい場所で撮るとブレが減ります。
  • ミッドソール側面（カメラ側）に赤い丸テープ（直径5〜8mm）を、かかとから靴の全長の約15%・42%・68%の位置に貼っておくと、自動検出のときに測定点をテープのすぐ横に合わせます。テープは上端・下端の境目から少し離して貼ってください。
  • 無負荷の基準は、指定した接地の瞬間のフレームです。接地の瞬間がブレていると基準の厚みもずれるので、明るい場所で撮影してください。
  • 基準より厚く見えたフレーム（計算上マイナス）は、画面では0%と表示します。CSVにはマイナスも含めた計算値をそのまま残しています。
  • 研究用途では、ミッドソール側面の3か所の上下に小さな黒い点を描いておくと、境目がはっきりして追跡が安定します。
